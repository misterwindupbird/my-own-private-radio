# My Own Private Radio

Support and privacy pages for My Own Private Radio, a Mac app that publishes your
NotebookLM Audio Overviews as a private podcast. Published with GitHub Pages at
<https://misterwindupbird.github.io/my-own-private-radio/>.

Questions and bug reports: [open an issue](https://github.com/misterwindupbird/my-own-private-radio/issues).
